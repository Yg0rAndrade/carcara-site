# Company Profile

- **Nome:** Carcará Code
- **Setor:** Ferramenta de desenvolvimento / IDE para IA
- **O que é:** Um aplicativo desktop (Electron, Windows) que coloca uma interface visual em cima do Claude Code. Serve para criar sites, sistemas e apps conversando com a IA, sem precisar entender de programação. Roda vários projetos ao mesmo tempo (multiplexador), tem seleção visual de elementos e preview ao vivo.
- **Público-alvo:** Pessoas leigas em programação ("vibe coders"), iniciantes que querem tirar uma ideia do papel sem escrever código. A comunicação deve assumir ZERO conhecimento técnico.
- **Tom de voz:** Acolhedor, direto, sem jargão. Explica tudo como se fosse para alguém que nunca abriu um terminal na vida. Usa analogias do dia a dia.
- **Produto gratuito e open source.**
