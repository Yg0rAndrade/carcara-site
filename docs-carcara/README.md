# docs-carcara (rastreador do loop de documentação)

Esta pasta NÃO é mais o destino das páginas. Ela guarda só o controle de
progresso do squad de documentação:

- `_mapa.md`: o mapa de abas e sub-abas com o checklist ([ ] pendente, [x] feita)
  e a coluna com o caminho de cada página.

As páginas publicadas ficam em `src/content/docs/docs/` e são servidas pelo
Starlight em **/docs** (com o tema creme + brasa do site). Para ver localmente:
`npm run dev` e abra `http://localhost:4321/docs`.
