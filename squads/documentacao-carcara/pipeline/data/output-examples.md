# Criar um projeto novo

## Pra que serve
É aqui que tudo começa. Um projeto é a "pasta" onde a sua ideia vai virar
realidade: um site, um app ou um sisteminha. Você cria um projeto para cada
ideia diferente que quiser tocar.

## Quando usar
- Quando você teve uma ideia nova e quer começar do zero.
- Quando quer separar dois trabalhos diferentes para não misturar.

## Passo a passo
1. Abra o Carcará Code. A tela inicial aparece.
2. Clique no botão "Novo Projeto", no canto de cima. Uma janelinha abre.
3. Digite um nome para a sua ideia (ex.: "Site da minha loja") e clique em Criar.
4. Pronto. O projeto aparece na barra lateral esquerda, e a IA já fica esperando
   você contar o que quer fazer.

## Dica
Dê nomes que você reconheça depois. "Loja da Ana" é melhor que "projeto 2".
```

# Conversar com a IA

## Pra que serve
O chat é onde você fala com a inteligência artificial como se fosse uma pessoa
que faz o trabalho para você. Você escreve o que quer ("crie uma página de
contato azul") e ela faz.

## Quando usar
- Sempre que quiser criar ou mudar alguma coisa no seu projeto.
- Quando algo deu errado e você quer pedir para a IA arrumar.

## Passo a passo
1. Com o projeto aberto, olhe para a caixa de texto embaixo, escrito "Digite...".
2. Escreva com suas palavras o que você quer. Pode ser simples, como falar com
   um amigo.
3. Aperte Enter. A IA começa a trabalhar e você vê o que ela está fazendo.
4. Quando ela termina, o resultado aparece no preview (a prévia do seu projeto).

## Deu errado?
Se a IA não entendeu, não tem problema. Escreva de novo com mais detalhe, ou
diga "não era isso, eu queria...". Ela tenta de novo.
```
