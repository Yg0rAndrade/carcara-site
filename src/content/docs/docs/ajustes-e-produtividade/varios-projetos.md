## Pra que serve
O Carcará Code guarda todos os seus projetos (cada ideia sua: um site, um
app) numa lista só, e deixa você pular de um para o outro rapidinho, sem
fechar nada. Assim você toca várias ideias diferentes sem perder o lugar.

## Quando usar
- Quando estiver trabalhando em mais de um projeto na mesma semana.
- Quando quiser dar uma olhada rápida em outro projeto e voltar para o
  atual.

## Passo a passo
1. Olhe para o rail, a barra fininha na ponta esquerda da tela. Cada
   projeto seu aparece como um ícone ali.
2. Clique no ícone do projeto que você quer abrir.
3. A tela inteira passa a mostrar aquele projeto: o chat e o preview dele (a
   prévia ao vivo, mostrando como o projeto está ficando de verdade).
4. Para voltar ao projeto anterior, clique no ícone dele de novo no rail.

## Trocar de projeto sem tirar as mãos do teclado
1. Aperte Ctrl+K (ou Cmd+K, no Mac) em qualquer lugar do aplicativo. Uma
   caixinha de busca aparece no meio da tela.
2. Digite o nome do projeto que você quer.
3. Aperte Enter no projeto certo. O Carcará troca para ele na hora.

## Dica
Só dá para ver um projeto por vez na tela, mas a troca é instantânea e nada
do que você estava fazendo se perde. Se quiser mesmo ver dois projetos lado
a lado, abra um segundo Carcará Code numa outra janela do seu computador.
