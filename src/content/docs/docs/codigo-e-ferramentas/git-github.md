## Pra que serve
O Git é como um álbum de fotos do seu projeto: a cada "foto" (chamada de
commit), ele guarda como tudo estava naquele momento, para você poder olhar
depois ou voltar atrás. O GitHub é onde essas fotos ficam guardadas na
internet, para você não perder nada e poder mostrar seu projeto para outras
pessoas.

## Quando usar
- Quando terminar uma parte do trabalho e quiser guardar esse momento.
- Quando quiser colocar o projeto na internet, no GitHub.
- Quando quiser ver o que mudou desde a última vez que salvou.

## Salvar uma versão (commit)
1. Clique na aba "Git", em cima do painel da direita.
2. Veja a lista "Alterações": são os arquivos que você (ou a IA) mudou desde
   a última vez que salvou.
3. Clique na caixa de texto escrito "Mensagem do commit" e escreva uma frase
   curta contando o que mudou (ex.: "página inicial pronta").
4. Clique no botão "Commit de tudo". Pronto, essa versão fica guardada.

## Ver o que mudou
1. Na lista de arquivos alterados, clique em um deles.
2. O texto muda de cor embaixo, mostrando linha por linha o que foi
   adicionado ou removido naquele arquivo.
3. Clique em "fechar" para sair dessa visualização.

## Publicar no GitHub pela primeira vez
1. Clique no botão "Publicar branch no GitHub" (branch é o nome que o Git dá
   para a linha de versões que você está seguindo; na maioria das vezes você
   só tem uma, então pode ignorar a palavra e seguir em frente).
2. Se ainda não tiver um repositório (a "pasta" do seu projeto lá no
   GitHub), clique no link "Criar um repositório no GitHub". Uma aba do
   navegador abre para você criar.
3. Volte para o Carcará Code e cole o endereço desse repositório na caixa
   que apareceu.
4. Clique em "Conectar e publicar". Seu projeto vai para o GitHub.

## Enviar novas versões depois da primeira vez
1. Depois de salvar uma versão (commit), clique no botão "Enviar commits pro
   GitHub".
2. Espere terminar. As suas versões novas ficam salvas lá também.

## Dica
Se for a sua primeira vez publicando, o Git pode pedir para você entrar com
sua conta do GitHub numa janela do próprio Windows ou do navegador. É só
seguir o que aparecer na tela.

## Deu errado?
Se aparecer um aviso vermelho dizendo que o Git não está instalado, clique
em "Baixar o Git" e siga a instalação. Depois, volte para o Carcará Code e
tente de novo.
