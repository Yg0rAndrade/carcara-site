## Pra que serve
O Carcará Code não trabalha só com uma inteligência artificial. Se o seu
projeto tiver mais de uma IA disponível (por exemplo, Claude e outra), você
escolhe qual delas vai trabalhar em cada aba de conversa.

## Quando usar
- Quando você configurou mais de uma IA para o mesmo projeto e quer decidir
  qual usar numa conversa nova.
- Quando quer comparar como IAs diferentes resolvem o mesmo pedido, cada uma
  numa aba.

## Passo a passo
1. Abra uma aba de conversa nova nesse projeto (veja como em "Várias sessões
   de chat"). Se o projeto tiver só uma IA, ela já entra sozinha e você nem
   vê essa tela.
2. Se houver mais de uma IA disponível, aparece a tela "Escolha a IA desta
   aba", com um card para cada uma.
3. Cada card mostra o nome da IA e uma frasezinha explicando o que ela é
   (por exemplo, "Sua assinatura Claude" ou "A IA da OpenAI, a mesma por trás
   do ChatGPT").
4. Clique no card da IA que você quer usar. A tela some, e a conversa começa
   direto com ela.

## E se a IA que eu quero não estiver instalada?
Alguns cards aparecem mais claros, meio apagados, com o aviso "Não instalada,
clique para instalar". Se você clicar num desses, o Carcará te leva para a
tela de instalação em vez de abrir a conversa. Veja o passo a passo em
"Instalar e gerenciar as IAs".

## Dica
Cada aba guarda a própria escolha. Isso quer dizer que, no mesmo projeto,
você pode ter uma aba conversando com uma IA e outra aba conversando com
outra, ao mesmo tempo, sem misturar.
