## Pra que serve
Você não precisa ficar preso a uma conversa só. Dá para abrir várias abas de
chat no mesmo projeto e trabalhar em coisas diferentes ao mesmo tempo. Cada
aba tem sua própria conversa, com sua própria IA trabalhando.

## Quando usar
- Quando quer pedir uma coisa nova sem perder o fio da conversa atual.
- Quando quer comparar duas ideias diferentes, cada uma numa aba.
- Quando quer ver duas conversas lado a lado na tela.

## Passo a passo
1. Olhe para cima do chat. Ali fica uma fileira de abas, uma para cada
   conversa aberta.
2. Para abrir uma conversa nova, clique no botão "+" no canto direito dessa
   fileira. Uma aba nova aparece, chamada "Sem título".
3. Escreva na nova aba. Depois de um tempo, o nome dela muda sozinho, para
   combinar com o assunto da conversa.
4. Para voltar a uma conversa antiga, clique na aba dela.

## Fechar e renomear uma aba
1. Passe o mouse sobre a aba. Um "x" pequeno aparece nela.
2. Clique no "x" para fechar essa conversa. (Só dá para fechar se houver mais
   de uma aba aberta: sempre precisa sobrar pelo menos uma.)
3. Para dar um nome só seu, clique com o botão direito na aba e escolha
   "Renomear".
4. Digite o novo nome e aperte Enter para salvar, ou Esc para desistir.

## Ver duas conversas ao mesmo tempo
Você pode arrastar uma aba para a borda da tela (esquerda, direita, cima ou
embaixo) para dividir a área do chat em duas partes. Assim, dá para ver duas
conversas lado a lado, cada uma trabalhando por conta própria.

## Dica
Cada aba tem uma bolinha colorida do lado do nome, mostrando se a IA está
trabalhando, pedindo confirmação ou esperando você. É um jeito rápido de ver
quais conversas já terminaram sem precisar clicar em cada uma.
