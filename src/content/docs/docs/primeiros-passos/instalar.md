## Pra que serve
Antes de usar o Carcará, você precisa instalá-lo no seu computador, do mesmo
jeito que instala qualquer outro programa. É rápido, é de graça, e você só faz
isso uma vez.

## Antes de começar
- O Carcará funciona no Windows. Se você usa Windows, está tudo certo.
- Deixe seu computador ligado na internet enquanto baixa.

## Passo a passo
1. Entre no site do Carcará Code pelo seu navegador (o programa que você usa para
   abrir sites, como o Chrome ou o Edge).
2. Procure o botão grande escrito "Baixar para Windows" e clique nele.
3. Um arquivo começa a baixar. Ele costuma aparecer embaixo, no cantinho do
   navegador. Espere terminar de baixar.
4. Clique duas vezes nesse arquivo que baixou. A instalação começa e uma janela
   abre.
5. Siga a instalação clicando em "Avançar" (ou "Próximo") até o final, e depois
   em "Concluir".
6. Pronto. O Carcará aparece na sua lista de programas e cria um atalho. É só
   abrir.

## Deu errado?
Se o Windows mostrar uma tela azul avisando que o programa é de um "editor
desconhecido", não se preocupe, é seguro. Clique em "Mais informações" e depois
no botão "Executar assim mesmo". Isso acontece porque o Carcará é um programa
aberto e gratuito, e o Windows só está sendo cuidadoso.

## Dica
Depois de instalar, ainda falta um passinho antes de criar seu primeiro projeto:
preparar o seu PC com as ferramentas que o Carcará usa. A próxima página te
guia nisso, com calma.
