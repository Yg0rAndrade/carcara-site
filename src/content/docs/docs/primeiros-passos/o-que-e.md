## Pra que serve
O Carcará Code é um programa para o seu computador que deixa você criar sites,
aplicativos e sisteminhas conversando com uma inteligência artificial, como se
fosse um bate-papo. Você escreve com suas palavras o que quer ("faça uma página
para a minha loja com os produtos e um botão de contato") e a IA constrói para
você. Você não precisa saber programar. Você fala, ela faz.

Pense nele como um ajudante que sabe programar e fica sentado do seu lado.
Você é o chefe: dá as ideias e vai pedindo mudanças. Ele faz o trabalho pesado.

## Como é a tela (as três partes)
Quando você abre um projeto, a tela se divide em três partes, da esquerda para
a direita:

1. **A barra lateral (o "rail")** fica na ponta esquerda. É a lista dos seus
   projetos. Cada projeto é uma ideia diferente sua. Você clica em um para abri-lo.
2. **O chat**, no meio, é onde você conversa com a IA. É aqui que você digita o
   que quer e acompanha o que ela está fazendo.
3. **O preview**, à direita, é a prévia ao vivo. É o seu site ou app aparecendo
   de verdade, já funcionando. Cada vez que a IA muda algo, essa prévia atualiza
   sozinha, na hora.

## O que você consegue fazer
- Criar um projeto do zero, mesmo sem ter nenhum arquivo pronto.
- Pedir mudanças conversando, quantas vezes quiser, até ficar do seu jeito.
- Ver o resultado ao vivo, sem precisar abrir outro programa.
- Tocar vários projetos ao mesmo tempo, cada um na sua "gavetinha" na barra lateral.

## Por onde começar
Se você acabou de conhecer o Carcará, o caminho é simples:

1. Instale o programa no seu computador (a próxima página ensina o passo a passo).
2. Prepare o PC com as ferramentas que ele usa (a gente te guia, é rápido).
3. Crie o seu primeiro projeto e comece a conversar com a IA.

## Dica
Não precisa decorar nada agora. O Carcará foi feito para quem nunca programou.
Você vai aprendendo conforme usa, e sempre pode pedir para a IA explicar ou
refazer qualquer coisa.
