## Pra que serve
O Carcará abre sozinho, mas ele trabalha em cima de algumas ferramentas que ficam
no seu computador. É como um fogão que precisa de gás para funcionar: o Carcará
precisa dessas ferramentas para mostrar seu projeto ao vivo e cuidar das versões.
Você instala o que faltar uma vez só, e pronto.

Quando você abre o Carcará pela primeira vez, aparece a tela "Vamos preparar seu
PC". Ela mostra o que já está pronto e o que ainda falta.

## As ferramentas que aparecem
- **Node.js**: é a mais importante. É ela que faz o preview funcionar, ou seja,
  ver o seu projeto rodando ao vivo. Sem o Node, o preview não aparece.
- **Git**: serve para salvar versões do seu trabalho e publicar no GitHub. É
  bom ter, mas dá para começar sem ele.
- **PHP**: só é preciso se o seu projeto for feito em PHP (um tipo de site). No
  Windows, o Carcará baixa isso sozinho quando precisa.

## Passo a passo
1. Na tela "Vamos preparar seu PC", olhe a lista de ferramentas.
2. Ao lado de cada uma, aparece um selo. Se estiver escrito "Instalado", essa já
   está pronta e você não precisa fazer nada.
3. Para as que faltam, clique no botão de instalar daquela ferramenta e espere.
4. Comece pelo Node.js, que é a essencial. Se ele pedir para escolher uma versão,
   escolha a que estiver marcada como "LTS" (é a mais estável).
5. Depois de instalar algo, clique em "Verificar de novo" para o Carcará conferir.
   O selo muda para "Instalado".
6. Quando o Node estiver pronto, você já pode criar seu primeiro projeto.

## Deu errado?
Essa tela não volta mais sozinha depois da primeira vez. Se você fechou antes de
terminar, ou quer conferir de novo, é só ir em Configurações e abrir a parte de
Dependências. Outro caminho: aperte as teclas Ctrl e K juntas e escreva "Preparar
meu PC".

## Dica
Não precisa instalar tudo agora. O Node.js já é o suficiente para começar. As
outras ferramentas você instala quando precisar delas, sem pressa.
