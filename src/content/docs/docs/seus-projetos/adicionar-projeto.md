## Pra que serve
Se você já tem um trabalho começado no seu computador (uma pasta com um site ou
app), dá para trazer ele para dentro do Carcará e continuar de onde parou. É como
colocar uma pasta que já existe numa estante nova: nada se perde, ela só passa a
ficar ali à mão.

## Quando usar
- Quando você já tinha um projeto no computador e quer mexer nele pelo Carcará.
- Quando alguém te passou uma pasta de projeto e você quer abri-la aqui.

## Passo a passo
1. Olhe para o rail, a barra de projetos na esquerda.
2. Clique no botão com o sinal de mais (+). Um menuzinho aparece.
3. Escolha a opção "Pasta local".
4. Uma janela do computador abre para você procurar a pasta do projeto.
5. Encontre a pasta, selecione ela e confirme.
6. Pronto. O projeto aparece no rail e você já pode clicar nele para abrir.

## Dica
Você pode adicionar várias pastas de uma vez nesse mesmo passo. Assim, se tiver
vários projetos guardados, traz todos juntos para o Carcará.
