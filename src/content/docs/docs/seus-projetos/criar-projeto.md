## Pra que serve
Quando você tem uma ideia nova e ainda não tem nada pronto, o Carcará cria o
projeto do zero para você. Você não precisa saber qual tecnologia usar nem montar
pasta nenhuma na mão: é só dizer o que quer, e ele prepara tudo pronto para
começar.

## Quando usar
- Quando teve uma ideia nova (um site, uma lojinha, um app) e quer partir do nada.
- Quando não sabe por onde começar nem qual ferramenta escolher.

## Passo a passo
1. No rail (a barra de projetos na esquerda), clique no botão de mais (+).
2. Escolha criar um novo projeto. A tela "Novo projeto" aparece.
3. Dê um nome para a sua ideia e confirme em "Criar projeto".
4. Com o projeto aberto, comece uma conversa nova no chat e escreva "/start".
5. A ajudante "/start" faz três perguntas simples sobre o que você quer.
6. Responda com suas palavras. Ela escolhe a tecnologia por você e deixa o
   projeto pronto para usar.

## Dica
O "/start" foi feito justamente para quem não é da área. Não precisa entender de
tecnologia: responda as três perguntas do seu jeito e deixe que ela decide o
resto.
