## Pra que serve
Quando você tem vários projetos, o rail (a barra na esquerda) pode ficar cheio.
Aqui você aprende a deixar tudo arrumado: juntar projetos em pastas, dar cores e
ícones e mudar a ordem. É como organizar uma estante por prateleiras e etiquetas,
para achar cada coisa num piscar de olhos.

## Quando usar
- Quando o rail está com muitos projetos e você quer separá-los por assunto.
- Quando quer bater o olho e reconhecer cada projeto na hora, pela cor ou ícone.

## Mudar a ordem dos projetos
1. Clique e segure um projeto no rail.
2. Arraste ele para cima ou para baixo.
3. Solte na posição que você quiser. A nova ordem fica salva.

## Juntar projetos numa pasta
1. Arraste um projeto para cima de outro.
2. Segure no centro do outro por um instante. Uma pasta se forma com os dois.
3. Para abrir ou fechar essa pasta, clique nela.
4. Para trocar o nome, clique com o botão direito na pasta e escolha
   "Renomear pasta".

## Dar cor e uma imagem a um projeto
1. Clique com o botão direito no projeto. Um menu aparece.
2. Escolha "Cor" para pintar o projeto, ou "Cor personalizada" para escolher um
   tom seu.
3. Escolha "Enviar imagem" para colocar uma figura que ajude a reconhecer o
   projeto de longe.

## Dica
Para renomear um projeto rápido, clique duas vezes no nome dele e digite o novo.
